DUGIL PET CENTER — site estático

Arquivos:
- index.html
- css.css
- js.js
- images/

Para testar: abra index.html no navegador.
O site usa Google Fonts, Lucide via CDN e um iframe estático do Google Maps, então esses itens precisam de internet para carregar.

Dados usados: material fornecido no pacote do Google Maps (Dugil Pet Center, Cuiabá).
